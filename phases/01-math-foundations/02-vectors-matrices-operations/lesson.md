### Эпоха 1: Рождение матриц (200 до н.э.)

Первое известное использование матриц — в древнекитайском трактате **"Математика в девяти книгах"** (около 200 г. до н.э.). Китайские математики использовали таблицы чисел для решения систем линейных уравнений — по сути, метод Гаусса за 2000 лет до Гаусса!

```
| 3  1  2 | 39 |
```

Это была чистая практичность: расчёт налогов, распределение зерна, землемерие.

### Эпоха 2: Формализация (1850-1900)

**Артур Кэли** в 1858 году публикует "Мемуар о теории матриц", где впервые формализует матричную алгебру как самостоятельную математическую дисциплину. Он вводит:
- Матричное умножение
- Обратную матрицу
- Транспонирование

**Джеймс Джозеф Сильвестр** (который и придумал термин "матрица" от латинского "matrx" — "матка, источник") видит в матрицах "родителей" определителей.

### Эпоха 3: Квантовая механика (1925)

**Вернер Гейзенберг** создаёт **матричную механику** — первую полную формулировку квантовой механики. Наблюдаемые физические величины (координата, импульс, энергия) представляются **бесконечными матрицами**.

**Макс Борн** и **Паскуаль Йордан** показывают, что коммутационное соотношение:

```
[p, q] = pq - qp = -iℏI
```

Где `p` и `q` — матрицы импульса и координаты, `I` — единичная матрица.

Это был первый случай, когда **некоммутативность матричного умножения** (AB ≠ BA) имела фундаментальное физическое значение!

### Эпоха 4: Компьютерная эра (1940-1960)

**Джон фон Нейман** использует матрицы для численного решения дифференциальных уравнений на ENIAC. 

В 1961 **Джеймс Уилкинсон** публикует "Theory and Practice in Linear Systems", заложив основы численной линейной алгебры. Его анализ ошибок округления в матричных операциях до сих пор используется.

Появляются первые библиотеки: **EISPACK** (1972) и **LINPACK** (1979), предшественники LAPACK.

### Эпоха 5: Нейросети и матрицы (1986-настоящее)

**1986:** Rumelhart, Hinton, Williams публикуют статью о backpropagation. Ключевая идея: градиенты распространяются **через матричные умножения** с использованием правила цепочки.

**1998:** LeCun создаёт LeNet-5 — первую практическую свёрточную сеть. Свёртки — это **специализированные матричные умножения** с разделением весов.

**2012:** AlexNet побеждает в ImageNet. Внутри — слои, каждый из которых есть `y = σ(Wx + b)`.

**2017:** "Attention Is All You Need". Self-attention — это:

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

Три матричных умножения + softmax. Вся мощь GPT-4 — в матричных операциях.

**2021:** **LoRA** (Low-Rank Adaptation) использует факторизацию матриц:

```
W' = W + BA, где B ∈ ℝ^(d×r), A ∈ ℝ^(r×d), r << d
```

Вместо обновления 4096×4096 = 16.7M параметров, обновляется 4096×16 + 16×4096 = 131K параметров. Линейная алгебра экономит миллионы долларов на обучении!

## 🧮 ЧАСТЬ 1: ELEMENT-WISE VS MATRIX MULTIPLICATION

### 1.1 Две разные вселенные

Это **самая частая ошибка** новичков в ML. Когда вы видите `A * B` в NumPy, это **НЕ** матричное умножение. Это element-wise (поэлементное) умножение. Матричное умножение обозначается `@` или `np.dot`.

**Почему это важно?** Потому что эти две операции имеют **совершенно разный геометрический смысл** и применяются в разных частях нейросети.

### 1.2 Element-wise умножение (Hadamard product)

**Определение:** Умножаем соответствующие элементы двух матриц **одинакового размера**.

```
| 1  2 |   | 5  6 |   | 1×5   2×6 |   | 5  12 |
| 3  4 | * | 7  8 | = | 3×7   4×8 | = | 21 32 |
```

**Требование:** Обе матрицы должны иметь **одинаковую форму** (или быть broadcastable).

**Геометрический смысл:** Это **не** трансформация пространства. Это просто покомпонентная операция, как сложение чисел.

**Код с нуля:**

```python
def element_wise_multiply(self, other):
    """Поэлементное умножение: A * B (Hadamard product)"""
    if self.shape != other.shape:
        raise ValueError(f"Shapes must match: {self.shape} vs {other.shape}")
    return Matrix([
        [self.data[i][j] * other.data[i][j] for j in range(self.cols)]
        for i in range(self.rows)
    ])
```

**Применение в AI:**
1. **Gating mechanisms:** В LSTM и GRU, gates используют element-wise multiplication для "фильтрации" информации:
   ```python
   cell_state = forget_gate * old_cell_state + input_gate * new_info
   ```

2. **Activation masking:** В attention, после softmax мы умножаем attention weights на values element-wise (для каждого элемента).

3. **Layer normalization:** Нормализация активаций через element-wise операции.

### 1.3 Matrix Multiplication (матричное умножение)

**Определение:** Каждая ячейка результата — это **скалярное произведение** строки первой матрицы на столбец второй.

```
| 1  2 |   | 5  6 |   | 1×5+2×7   1×6+2×8 |   | 19  22 |
| 3  4 | @ | 7  8 | = | 3×5+4×7   3×6+4×8 | = | 43  50 |
```

**Требование:** Количество **столбцов первой** = количеству **строк второй**.

```
(m × n) @ (n × p) = (m × p)
  ↑        ↑          ↑
строки   inner      столбцы
A      (должно      B
       совпадать)
```

**Геометрический смысл:** Это **композиция трансформаций**. Если A трансформирует пространство одним способом, а B — другим, то B @ A применяет сначала A, потом B.

**Код с нуля:**

```python
def matmul(self, other):
    """Матричное умножение: A @ B"""
    if self.cols != other.rows:
        raise ValueError(
            f"Inner dimensions must match: {self.cols} vs {other.rows}"
        )
    
    result_data = []
    for i in range(self.rows):
        row = []
        for j in range(other.cols):
            # Скалярное произведение i-й строки self на j-й столбец other
            value = sum(
                self.data[i][k] * other.data[k][j]
                for k in range(self.cols)
            )
            row.append(value)
        result_data.append(row)
    
    return Matrix(result_data)
```

**Применение в AI:**
1. **Полносвязный слой:** `output = W @ input + bias`
2. **Attention:** `scores = Q @ K.T`
3. **Свёртки (в форме im2col):** Свёртки сводятся к матричным умножениям
4. **Рекуррентные связи:** `h_t = W_h @ h_{t-1} + W_x @ x_t`

### 1.4 Сравнительная таблица

| Аспект | Element-wise (`*`) | Matrix (`@`) |
|--------|-------------------|--------------|
| **Обозначение в math** | A ⊙ B (Hadamard) | A × B или AB |
| **Обозначение в NumPy** | `A * B` | `A @ B` или `np.dot(A, B)` |
| **Требование к формам** | Одинаковые (или broadcastable) | `A.cols == B.rows` |
| **Результат для (m×n) и (n×p)** | Ошибка (если m≠n или n≠p) | (m×p) |
| **Геометрический смысл** | Покомпонентная операция | Композиция трансформаций |
| **Коммутативность** | Да: A ⊙ B = B ⊙ A | **НЕТ:** AB ≠ BA (в общем случае) |
| **Ассоциативность** | Да | Да |
| **Применение в нейросетях** | Gates, маски, нормализация | Слои, attention, RNN |

### 1.5 Почему AB ≠ BA (и это важно!)

Это один из самых **контринтуитивных** фактов линейной алгебры. В обычной алгебре 3×5 = 5×3. Но для матриц порядок **критически важен**.

**Пример:**

```
A = | 1  2 |    B = | 5  6 |
    | 3  4 |        | 7  8 |

AB = | 19  22 |    BA = | 23  34 |
     | 43  50 |         | 31  46 |

AB ≠ BA
```

**Геометрическая интерпретация:**
- AB = "сначала поверни (B), потом растяни (A)"
- BA = "сначала растяни (A), потом поверни (B)"

Очевидно, что результат разный! Представьте, что вы рисуете картину: порядок мазков кистью важен.

**Применение в AI:** Это причина, почему в трансформерах **Q и K нельзя менять местами** в `QKᵀ`. Запрос проецируется на ключи, а не наоборот.

## 🔄 ЧАСТЬ 2: BROADCASTING — МАГИЯ ФОРМ

### 2.1 Проблема: несовпадение форм

Рассмотрим типичную ситуацию в нейросети. У вас есть:
- Матрица выходов слоя: форма (2, 3) — 2 примера, 3 нейрона
- Вектор смещений (bias): форма (3,) — по одному на нейрон

```
Выходы:        Bias:
| 1  2  3 |    [10, 20, 30]
| 4  5  6 |
```

Как их сложить? Формы не совпадают! Наивный подход — использовать цикл:

```python
# Наивно и медленно
result = []
for i in range(outputs.rows):
    row = []
    for j in range(outputs.cols):
        row.append(outputs.data[i][j] + bias[j])
    result.append(row)
```

Но NumPy делает это **мгновенно и без циклов**, через broadcasting.

### 2.2 Что такое broadcasting?

**Определение:** Broadcasting — это набор правил, которые позволяют NumPy выполнять операции над массивами **разных форм**, автоматически "растягивая" меньший массив до формы большего.

**Ключевая идея:** Broadcasting **не создаёт копии данных**. NumPy просто "представляет", что меньший массив растянут, и выполняет операцию эффективно.

### 2.3 Правила broadcasting

NumPy сравнивает формы массивов **справа налево** (с последних измерений). Два измерения совместимы, если:
1. Они **равны**, или
2. Одно из них равно **1**

Если условие не выполняется — `ValueError: operands could not be broadcast together`.

**Алгоритм:**
```
Шаг 1: Выравниваем формы справа
Шаг 2: Сравниваем попарно, справа налево
Шаг 3: Если размерности совместимы — broadcasting работает
Шаг 4: Размерности = 1 "растягиваются" до нужного размера
```

### 2.4 Примеры broadcasting

#### Пример 1: Matrix + Vector (bias addition)

```
A: shape (2, 3)    b: shape (3,)

| 1  2  3 |   +   [10, 20, 30]
| 4  5  6 |

Шаг 1: Выравниваем справа
A: (2, 3)
b:    (3,)  ← добавляем виртуальную 1 слева: (1, 3)

Шаг 2: Сравниваем
A: 2  3
b: 1  3   ← 2 vs 1: OK (1 растягивается до 2)
        ← 3 vs 3: OK (равны)

Шаг 3: Broadcasting работает!
b "растягивается" до (2, 3):

| 1  2  3 |   | 10  20  30 |   | 11  22  33 |
| 4  5  6 | + | 10  20  30 | = | 14  25  36 |
```

**Код:**

```python
import numpy as np

outputs = np.array([[1, 2, 3], [4, 5, 6]])
bias = np.array([10, 20, 30])

result = outputs + bias
# array([[11, 22, 33],
#        [14, 25, 36]])
```

#### Пример 2: Matrix + Column Vector

```
A: shape (2, 3)    b: shape (2, 1)

| 1  2  3 |   | 10 |
| 4  5  6 | + | 20 |

Шаг 1: Выравниваем
A: 2  3
b: 2  1   ← 2 vs 2: OK, 3 vs 1: OK (1 растягивается до 3)

Шаг 2: b растягивается по горизонтали
| 10  10  10 |
| 20  20  20 |

Шаг 3: Складываем
| 11  12  13 |
| 24  25  26 |
```

#### Пример 3: Outer product через broadcasting

```python
a = np.array([1, 2, 3, 4])  # shape (4,)
b = np.array([10, 20, 30])  # shape (3,)

# Превращаем a в column vector
a_col = a[:, np.newaxis]  # shape (4, 1)

# Broadcasting делает outer sum
result = a_col + b  # shape (4, 3)
# array([[11, 21, 31],
#        [12, 22, 32],
#        [13, 23, 33],
#        [14, 24, 34]])
```

#### Пример 4: Несовместимые формы

```
A: shape (4, 3)    b: shape (4,)

A: 4  3
b:    4   ← добавляем 1 слева: (1, 4)

Сравниваем справа налево:
A: 4  3
b: 1  4   ← 3 vs 4: ОШИБКА! Не равны и ни одно не равно 1

ValueError: operands could not be broadcast together
```

### 2.5 Визуальная таблица broadcasting

| A shape | B shape | Result shape | Комментарий |
|---------|---------|--------------|-------------|
| (2, 3) | (3,) | (2, 3) | Bias addition |
| (2, 3) | (2, 1) | (2, 3) | Column bias |
| (5, 4) | (1,) | (5, 4) | Scalar addition |
| (5, 4) | (4,) | (5, 4) | Row broadcasting |
| (15, 3, 5) | (15, 1, 5) | (15, 3, 5) | 3D broadcasting |
| (15, 3, 5) | (3, 5) | (15, 3, 5) | 2D to 3D |
| (15, 3, 5) | (3, 1) | (15, 3, 5) | Partial broadcast |
| (3,) | (4,) | **ОШИБКА** | Несовместимы |
| (2, 1) | (8, 4, 3) | **ОШИБКА** | Несовместимы |

### 2.6 Broadcasting в нейросетях

**Где это используется:**

1. **Bias addition в dense layers:**
   ```python
   # В PyTorch:
   output = torch.matmul(input, weights.t()) + bias
   # bias имеет форму (output_dim,), input имеет (batch, input_dim)
   # broadcasting автоматически добавляет bias к каждому примеру в batch
   ```

2. **Batch normalization:**
   ```python
   # mean и variance имеют форму (features,)
   # input имеет форму (batch, features)
   normalized = (input - mean) / sqrt(variance + eps)
   # broadcasting для каждой выборки в batch
   ```

3. **Attention scores:**
   ```python
   # Q: (batch, seq_len, d_k)
   # K: (batch, seq_len, d_k)
   scores = torch.matmul(Q, K.transpose(-2, -1)) / sqrt(d_k)
   # Результат: (batch, seq_len, seq_len)
   ```

4. **Loss functions:**
   ```python
   # predictions: (batch, classes)
   # targets: (batch,) - class indices
   # Broadcasting при one-hot encoding и cross-entropy
   ```

### 2.7 Опасности broadcasting

Broadcasting — мощный инструмент, но может привести к **молчаливым багам**:

```python
a = np.array([[1, 2, 3], [4, 5, 6]])  # (2, 3)
b = np.array([1, 2, 3])  # (3,)

# Что произойдёт?
result = a - b  # (2, 3) - (3,) → broadcasting → (2, 3)

# А если мы ошиблись и b должна была быть (2,)?
b_wrong = np.array([1, 2])  # (2,)
# result = a - b_wrong  # ОШИБКА! (2, 3) и (2,) не broadcastable

# Но если случайно сделать:
b_transposed = np.array([[1], [2]])  # (2, 1)
result = a - b_transposed  # (2, 3) - (2, 1) → (2, 3)
# Это работает, но может быть не тем, что мы хотели!
```

**Совет инженера:** Всегда проверяйте формы через `.shape` перед операциями. Используйте `assert` statements:

```python
assert output.shape == expected_shape, f"Expected {expected_shape}, got {output.shape}"
```

## 🔄 ЧАСТЬ 3: ТРАНСПОНИРОВАНИЕ — СЕКRET BACKPROPAGATION

### 3.1 Что такое транспонирование?

**Определение:** Транспонирование — это операция, которая "переворачивает" матрицу: строки становятся столбцами, столбцы — строками.

```
A = | 1  2  3 |    Aᵀ = | 1  4 |
    | 4  5  6 |         | 2  5 |
                        | 3  6 |

Shape: (2, 3)         Shape: (3, 2)
```

**Формально:** `Aᵀ[i, j] = A[j, i]`

**Код с нуля:**

```python
def transpose(self):
    """Транспонирование: Aᵀ"""
    return Matrix([
        [self.data[j][i] for j in range(self.rows)]
        for i in range(self.cols)
    ])
```

### 3.2 Свойства транспонирования

```
(Aᵀ)ᵀ = A                 # Двойное транспонирование = оригинал
(A + B)ᵀ = Aᵀ + Bᵀ        # Транспонирование суммы
(cA)ᵀ = cAᵀ               # Скаляр выносится
(AB)ᵀ = BᵀAᵀ              # ВНИМАНИЕ: порядок меняется!
```

**Последнее свойство — критически важное!** При транспонировании произведения матриц **порядок множителей меняется**.

### 3.3 Транспонирование в backpropagation

Это одна из самых **элегантных** идей в ML. Вспомним forward pass полносвязного слоя:

```
y = Wx + b
```

Где:
- x: входной вектор (dim: n)
- W: матрица весов (shape: m × n)
- y: выходной вектор (dim: m)
- b: bias (dim: m)

В backpropagation нам нужно вычислить **градиент функции потерь L по W**, зная градиент по y:

```
∂L/∂W = (∂L/∂y) × xᵀ
```

Обратите внимание на **xᵀ**! Без транспонирования мы не смогли бы правильно "согласовать" формы для матричного умножения.

**Размерности:**

```
∂L/∂y: shape (m, 1)
xᵀ:    shape (1, n)

∂L/∂W = (m, 1) @ (1, n) = (m, n)  ✓ совпадает с формой W
```

**Геометрическая интерпретация:**
- В forward pass: W **проецирует** x из n-мерного пространства в m-мерное.
- В backward pass: Wᵀ **проецирует** градиент обратно из m-мерного в n-мерное пространство.

Это как **движение назад по тому же пути**, но в обратном направлении!

### 3.4 Транспонирование в Attention

В механизме self-attention трансформеров:

```python
# Q, K, V: shape (batch, seq_len, d_model)

# Для вычисления attention scores нужно:
# Q @ Kᵀ

# Q: (batch, seq_len, d_k)
# K: (batch, seq_len, d_k)
# Kᵀ: (batch, d_k, seq_len)  ← транспонируем последние 2 измерения
# Q @ Kᵀ: (batch, seq_len, seq_len)  ← попарные сходства
```

**Почему именно Kᵀ?** Потому что мы хотим вычислить **скалярное произведение каждого query с каждым key**. Это outer product в batch-формате.

```python
# В PyTorch:
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
```

## 📏 ЧАСТЬ 4: ДЕТЕРМИНАНТ — МЕРА "СЖАТИЯ" ПРОСТРАНСТВА

### 4.1 Интуитивное определение

**Детерминант** (определитель) квадратной матрицы — это **одно число**, которое говорит, как матрица трансформирует **площадь (в 2D)** или **объём (в 3D)**.

- `det(A) > 0`: Трансформация сохраняет ориентацию, растягивает площадь в det(A) раз
- `det(A) < 0`: Трансформация **отражает** пространство (меняет ориентацию)
- `det(A) = 0`: Трансформация **сжимает** пространство в меньшую размерность (потеря информации!)
- `|det(A)| = 1`: Трансформация сохраняет площадь/объём

### 4.2 Визуальная интерпретация

Представьте единичный квадрат (площадь = 1):

```
До:                После (A = [[2, 0], [0, 3]]):
  y                  y
  ↑                  ↑
1 |  •———•          3 |     •—————•
  |  |   |            |     |     |
  |  |   |            |     |     |
0 +--•———•→x         0 +----•-----•——→x
  0     1              0         2

Площадь = 1          Площадь = 6 = det(A) = 2×3
```

**Пример с отрицательным детерминантом:**

```
A = | -1  0 |    det(A) = -1
    |  0  1 |

Это отражение относительно оси Y.
Площадь сохраняется (|det| = 1), но ориентация меняется.
```

### 4.3 Формулы вычисления

#### Для 1×1:

```
A = [a]    det(A) = a
```

#### Для 2×2:

```
A = | a  b |    det(A) = ad - bc
    | c  d |
```

**Мнемоника:** "произведение главной диагонали минус произведение побочной".

#### Для 3×3 (правило Саррюса):

```
A = | a  b  c |
    | d  e  f |
    | g  h  i |

det(A) = a(ei - fh) - b(di - fg) + c(dh - eg)
```

#### Для n×n (разложение по строке):

```
det(A) = Σⱼ (-1)^(i+j) × A[i,j] × det(M[i,j])
```

Где `M[i,j]` — минор (матрица без i-й строки и j-го столбца).

### 4.4 Код с нуля

```python
def determinant(self):
    """
    Вычисление детерминанта (определителя).
    Использует рекурсивное разложение по первой строке.
    """
    if self.rows != self.cols:
        raise ValueError("Determinant only defined for square matrices")
    
    # Базовые случаи
    if self.shape == (1, 1):
        return self.data[0][0]
    
    if self.shape == (2, 2):
        return (self.data[0][0] * self.data[1][1] - 
                self.data[0][1] * self.data[1][0])
    
    # Рекурсивное разложение по первой строке
    det = 0
    for j in range(self.cols):
        # Создаём минор (матрица без 0-й строки и j-го столбца)
        minor_data = [
            [self.data[i][k] for k in range(self.cols) if k != j]
            for i in range(1, self.rows)
        ]
        minor = Matrix(minor_data)
        
        # Чередуем знаки: +, -, +, -, ...
        sign = (-1) ** j
        det += sign * self.data[0][j] * minor.determinant()
    
    return det
```

### 4.5 Детерминант в AI

**Где это важно:**

1. **Проверка обратимости:** Матрица обратима ⟺ det(A) ≠ 0. Если det(A) = 0, матрица "вырождена" (singular), и обратная не существует.

2. **Normalizing Flows:** В генеративных моделях, при замене переменных, нужно умножать на |det(J)|, где J — якобиан трансформации.

3. **Multivariate Gaussian:** Плотность нормального распределения:
   ```
   p(x) = (1/√((2π)^k |Σ|)) × exp(-½(x-μ)ᵀΣ⁻¹(x-μ))
   ```
   Где |Σ| = det(Σ) — детерминант ковариационной матрицы.

4. **Numerical stability:** Если |det(A)| очень мал (близок к 0), матрица **плохо обусловлена** (ill-conditioned). Малые изменения входа дают огромные изменения выхода.

5. **Change of variables:** В VAE и других генеративных моделях, при переходе между latent space и data space, нужно учитывать детерминант якобиана.

### 4.6 Свойства детерминанта

```
det(AB) = det(A) × det(B)
det(Aᵀ) = det(A)
det(A⁻¹) = 1/det(A)
det(cA) = cⁿ × det(A), где A — n×n матрица
det(I) = 1
```

**Интересный факт:** `det(AB) = det(A) × det(B)` означает, что композиция трансформаций умножает их "коэффициенты растяжения".

## 🔄 ЧАСТЬ 5: ОБРАТНАЯ МАТРИЦА — КОГДА ТРАНСФОРМАЦИЯ ОБРАТИМА

### 5.1 Интуитивное определение

**Обратная матрица** A⁻¹ — это матрица, которая **"отменяет"** действие A:

```
A × A⁻¹ = A⁻¹ × A = I
```

Где I — единичная матрица.

**Геометрически:** Если A — это "поворот на 30°", то A⁻¹ — это "поворот на -30°". Если A растягивает пространство в 2 раза, то A⁻¹ сжимает в 2 раза.

### 5.2 Когда существует обратная?

Обратная матрица существует **только если**:
1. Матрица **квадратная** (n × n)
2. **det(A) ≠ 0** (матрица невырожденная)

Если det(A) = 0, матрица **сингулярна** (singular) — она "сплющивает" пространство в меньшую размерность, и информация теряется. Обратного преобразования не существует.

**Пример сингулярной матрицы:**

```
A = | 1  2 |    det(A) = 1×2 - 2×1 = 0
    | 1  2 |

Эта матрица проецирует всё на прямую y = x.
Информация о перпендикулярном направлении теряется.
```

### 5.3 Формула для 2×2

Для матрицы 2×2 есть простая формула:

```
A = | a  b |    A⁻¹ = (1/det(A)) × |  d  -b |
    | c  d |                       | -c   a |
```

**Мнемоника:**
1. Поменять местами `a` и `d`
2. Поменять знаки `b` и `c`
3. Разделить на детерминант

**Код:**

```python
def inverse_2x2(self):
    """
    Обратная матрица для 2×2.
    Формула: (1/det) * [[d, -b], [-c, a]]
    """
    if self.shape != (2, 2):
        raise ValueError("inverse_2x2 only works for 2x2 matrices")
    
    det = self.determinant()
    if abs(det) < 1e-10:
        raise ValueError(f"Matrix is singular (det={det}), no inverse exists")
    
    a, b = self.data[0][0], self.data[0][1]
    c, d = self.data[1][0], self.data[1][1]
    
    return Matrix([
        [d / det, -b / det],
        [-c / det, a / det]
    ])
```

### 5.4 Обратная для 3×3 и больше

Для больших матриц используется **метод присоединённой матрицы** (adjugate method) или **LU-разложение**. Это сложнее и выходит за рамки нашего курса, но идея та же:

```
A⁻¹ = (1/det(A)) × adj(A)
```

Где `adj(A)` — присоединённая матрица (транспонированная матрица алгебраических дополнений).

**На практике** никогда не вычисляйте обратную вручную для больших матриц. Используйте `np.linalg.inv` или `torch.linalg.inv`, которые используют устойчивые численные методы.

### 5.5 Свойства обратной матрицы

```
(A⁻¹)⁻¹ = A
(AB)⁻¹ = B⁻¹A⁻¹           # ВНИМАНИЕ: порядок меняется!
(Aᵀ)⁻¹ = (A⁻¹)ᵀ
(cA)⁻¹ = (1/c)A⁻¹
```

**Критически важное:** `(AB)⁻¹ = B⁻¹A⁻¹`. Чтобы "отменить" композицию трансформаций, нужно отменять их **в обратном порядке**.

**Аналогия:** Если вы надели носки (A), потом ботинки (B), то чтобы раздеться, нужно сначала снять ботинки (B⁻¹), потом носки (A⁻¹).

### 5.6 Обратная матрица в AI

**Где это важно:**

1. **Решение систем линейных уравнений:**
   ```
   Ax = b    →    x = A⁻¹b
   ```
   Это основа **linear regression** (normal equation):
   ```
   w = (XᵀX)⁻¹Xᵀy
   ```

2. **Whitening transforms:** В data preprocessing, мы хотим сделать данные "белым шумом" (нулевая корреляция, единичная дисперсия):
   ```
   x_white = Σ^(-1/2) × (x - μ)
   ```

3. **Kalman filters:** В reinforcement learning и control theory, обновление состояния включает обратные матрицы ковариации.

4. **Natural gradient descent:** В продвинутой оптимизации:
   ```
   θ_new = θ - η × F⁻¹ × ∇L
   ```
   Где F — Fisher information matrix.

5. **Gaussian processes:** Предсказание требует обращения ковариационной матрицы:
   ```
   μ* = K*ᵀK⁻¹y
   ```

### 5.7 Опасности обращения матриц

**Problem 1: Numerical instability**

Если det(A) очень мал (но не 0), обратная матрица существует, но **численно неустойчива**. Малые ошибки округления дают огромные ошибки в результате.

```python
import numpy as np

A = np.array([[1, 1], [1, 1.0001]])
# det(A) = 0.0001 (очень мал!)
A_inv = np.linalg.inv(A)
# A_inv = [[10001, -10000], [-10000, 10000]]
# Огромные числа! Малые изменения входа → огромные изменения выхода
```

**Решение:** Используйте **condition number** (число обусловленности):
```python
cond = np.linalg.cond(A)
# Если cond > 1e10, матрица плохо обусловлена
```

**Problem 2: Вычислительная сложность**

Обращение матрицы n×n имеет сложность **O(n³)**. Для больших матриц (например, 10000×10000) это очень дорого.

**Решение:** Вместо явного обращения используйте:
- `np.linalg.solve(A, b)` вместо `A_inv @ b`
- **Cholesky decomposition** для положительно определённых матриц
- **Conjugate gradient** для разреженных матриц

## 🆔 ЧАСТЬ 6: ЕДИНИЧНАЯ МАТРИЦА — НЕЙТРАЛЬНЫЙ ЭЛЕМЕНТ

### 6.1 Определение

**Единичная матрица** (identity matrix) I — это квадратная матрица с единицами на главной диагонали и нулями везде:

```
I = | 1  0  0 |
    | 0  1  0 |
    | 0  0  1 |
```

**Свойство:** `AI = IA = A` для любой матрицы A подходящего размера.

**Аналогия:** Это как умножение на 1 в обычной алгебре. "Нейтральный элемент" матричного умножения.

### 6.2 Код с нуля

```python
@staticmethod
def identity(n):
    """
    Создаёт единичную матрицу n×n.
    Использование: I = Matrix.identity(3)
    """
    return Matrix([
        [1 if i == j else 0 for j in range(n)]
        for i in range(n)
    ])
```

### 6.3 Свойства единичной матрицы

```
AI = IA = A
I⁻¹ = I
det(I) = 1
Iᵀ = I
Iⁿ = I для любого n
```

### 6.4 Единичная матрица в AI

**Где это критически важно:**

1. **Residual Connections (ResNets):**
   ```python
   # ResNet block:
   output = x + F(x)  # где F - несколько слоёв
   
   # Если F(x) = 0, то output = x (тождественное преобразование)
   # Это эквивалентно умножению на единичную матрицу
   ```
   Residual connections позволяют градиентам "течь" через сеть, решая проблему vanishing gradients.

2. **Initialization:**
   ```python
   # Identity initialization для RNN:
   W_hh = np.eye(hidden_dim)  # Начальные веса = единичная матрица
   
   # Это помогает избежать vanishing/exploding gradients в начале обучения
   ```

3. **Regularization (Ridge regression):**
   ```python
   w = (XᵀX + λI)⁻¹Xᵀy
   ```
   Добавление λI делает матрицу (XᵀX + λI) **всегда обратимой**, даже если XᵀX сингулярна.

4. **Batch Normalization:**
   ```python
   # В inference mode, если γ=1 и β=0:
   # BatchNorm превращается в тождественное преобразование
   ```

5. **Attention masking:**
   ```python
   # Causal mask в трансформерах:
   mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
   # Верхнетреугольная матрица из единиц
   ```

### 6.5 Диагональные матрицы

**Обобщение единичной матрицы:** Диагональная матрица имеет ненулевые элементы только на главной диагонали:

```
D = | 2  0  0 |
    | 0  3  0 |
    | 0  0  5 |
```

**Свойства:**
- Умножение на D **масштабирует** каждую координату независимо
- D⁻¹ легко вычислить: просто инвертировать диагональные элементы
- det(D) = произведение диагональных элементов

**Применение:** Weight initialization, scaling, preconditioning в оптимизации.

## 🧠 ЧАСТЬ 7: DENSE LAYER НЕЙРОСЕТИ — ПРИМЕНЯЕМ ВСЁ

### 7.1 Анатомия полносвязного слоя

Теперь, когда у нас есть все кирпичики, давайте построим **настоящий dense layer** (fully connected layer) нейросети.

**Формула:**

```
y = activation(W @ x + b)
```

Где:
- `x`: входной вектор (dim: input_size)
- `W`: матрица весов (shape: output_size × input_size)
- `b`: вектор смещений (dim: output_size)
- `activation`: нелинейная функция (ReLU, sigmoid, tanh)
- `y`: выходной вектор (dim: output_size)

**Визуализация:**

```
Вход x (3D):         Веса W (2×3):         Выход y (2D):
                     
  [x₁]               [w₁₁  w₁₂  w₁₃]        [y₁]
  [x₂]       →       [w₂₁  w₂₂  w₂₃]   →    [y₂]
  [x₃]
                     
                     + bias b (2D):
                     [b₁]
                     [b₂]
                     
                     ↓ activation (ReLU)
                     
                     [max(0, y₁)]
                     [max(0, y₂)]
```

### 7.2 Размеры матриц

**Почему W имеет форму (output_size × input_size)?**

Потому что мы хотим:

```
W @ x = y
(output × input) @ (input × 1) = (output × 1)
```

Каждая **строка** матрицы W — это веса одного **нейрона** выходного слоя.

```
W = | w₁₁  w₁₂  w₁₃ |    ← веса нейрона 1
    | w₂₁  w₂₂  w₂₃ |    ← веса нейрона 2
```

**Выход y[0]** = скалярное произведение **первой строки W** на **x**:

```
y₁ = w₁₁×x₁ + w₁₂×x₂ + w₁₃×x₃ + b₁
```

### 7.3 Зачем нужен bias?

Без bias:

```
y = W @ x
```

Если x = 0 (все нули), то y = 0 (тоже все нули). Нейрон не может "активироваться" при нулевом входе.

С bias:

```
y = W @ x + b
```

Даже если x = 0, y = b. Bias позволяет нейрону иметь **базовую активность**, независимо от входа.

**Геометрически:** Bias **сдвигает** гиперплоскость решения. В линейной регрессии, bias — это y-intercept (точка пересечения с осью Y).

### 7.4 Зачем нужна активация?

Без активации:

```
y₁ = W₁ @ x + b₁
y₂ = W₂ @ y₁ + b₂ = W₂ @ (W₁ @ x + b₁) + b₂ = (W₂W₁) @ x + (W₂b₁ + b₂)
```

Видите? Двухслойная сеть без активации **эквивалентна однослойной**! Матрицы просто перемножаются.

**С активацией:**

```
y₁ = ReLU(W₁ @ x + b₁)
y₂ = ReLU(W₂ @ y₁ + b₂)
```

Теперь это **настоящая глубокая сеть**, способная аппроксимировать любую функцию (Universal Approximation Theorem).

**Почему ReLU?**

```python
def relu(x):
    return max(0, x)
```

1. **Вычислительно дёшев:** просто сравнение
2. **Решает проблему vanishing gradients:** для x > 0, градиент = 1
3. **Индуцирует разреженность:** многие нейроны "выключаются" (output = 0)

### 7.5 Batch processing

В реальности мы обрабатываем **не один пример, а целый batch** для эффективности:

```
X: shape (batch_size, input_size)
W: shape (output_size, input_size)
b: shape (output_size,)

Y = X @ Wᵀ + b    # shape (batch_size, output_size)
```

**Почему Wᵀ?** Потому что в PyTorch/TensorFlow принято хранить примеры в **строках** (row-major):

```
X = | x₁₁  x₁₂  x₁₃ |    ← пример 1
    | x₂₁  x₂₂  x₂₃ |    ← пример 2

W = | w₁₁  w₁₂  w₁₃ |    ← нейрон 1
    | w₂₁  w₂₂  w₂₃ |    ← нейрон 2

X @ Wᵀ = | x₁₁  x₁₂  x₁₃ | @ | w₁₁  w₂₁ | = | y₁₁  y₁₂ |
         | x₂₁  x₂₂  x₂₃ |   | w₁₂  w₂₂ |   | y₂₁  y₂₂ |
                               | w₁₃  w₂₃ |

Результат: (batch_size × output_size)
```

**Broadcasting для bias:**

```
Y = X @ Wᵀ + b
    (batch, out) + (out,)  ← broadcasting!
```

Bias `[b₁, b₂]` автоматически добавляется к **каждому примеру** в batch.

### 7.6 Полный код dense layer с нуля

```python
import random

class DenseLayer:
    """
    Полносвязный слой нейросети с нуля.
    
    Forward pass: y = ReLU(W @ x + b)
    """
    
    def __init__(self, input_size, output_size):
        self.input_size = input_size
        self.output_size = output_size
        
        # Xavier initialization: веса из N(0, sqrt(2/(in+out)))
        std = (2 / (input_size + output_size)) ** 0.5
        self.weights = Matrix([
            [random.gauss(0, std) for _ in range(input_size)]
            for _ in range(output_size)
        ])
        
        # Bias инициализируем нулями
        self.bias = Matrix([[0.0] for _ in range(output_size)])
    
    def forward(self, x):
        """
        Forward pass.
        x: Matrix shape (input_size, 1)
        return: Matrix shape (output_size, 1)
        """
        # Линейная трансформация
        z = self.weights.matmul(x) + self.bias
        
        # ReLU activation
        output = Matrix([
            [max(0.0, val) for val in row]
            for row in z.data
        ])
        
        return output

# Входной вектор

# Forward pass

```

### 7.7 Что произошло?

Давайте разберём **пошагово**:

**Шаг 1: Инициализация весов**

```python
self.weights = Matrix([
    [0.12, -0.34, 0.56],   # нейрон 1
    [-0.23, 0.45, -0.67]   # нейрон 2
])
# Xavier init: веса малы, чтобы избежать exploding gradients
```

**Шаг 2: Линейная трансформация**

```python
z = W @ x + b

  | 0.12  -0.34   0.56 |   |  0.5 |   | 0.0 |
  | -0.23  0.45  -0.67 | @ |  0.8 | + | 0.0 |
                         | -0.3 |

= | 0.12×0.5 + (-0.34)×0.8 + 0.56×(-0.3) |   | 0 |
  | -0.23×0.5 + 0.45×0.8 + (-0.67)×(-0.3) | + | 0 |

= | 0.06 - 0.272 - 0.168 |   | -0.38 |
  | -0.115 + 0.36 + 0.201| = |  0.446|
```

**Шаг 3: ReLU activation**

```python
output = ReLU(z) = ReLU([[-0.38], [0.446]])
                 = [[0.0], [0.446]]
```

Первый нейрон "выключился" (отрицательный вход → 0), второй остался активным.

**Результат:** Входной вектор (3D) трансформирован в выходной вектор (2D), где одна координата обнулена нелинейностью.

### 8.1 Класс Vector

```python
class Vector:
    """Вектор — упорядоченный список чисел."""
    
    def __init__(self, data):
        self.data = list(data)
        self.size = len(self.data)
    
    def __repr__(self):
        return f"Vector({self.data})"
    
    def __add__(self, other):
        """Сложение векторов."""
        if self.size != other.size:
            raise ValueError(f"Size mismatch: {self.size} vs {other.size}")
        return Vector([a + b for a, b in zip(self.data, other.data)])
    
    def __sub__(self, other):
        """Вычитание векторов."""
        if self.size != other.size:
            raise ValueError(f"Size mismatch: {self.size} vs {other.size}")
        return Vector([a - b for a, b in zip(self.data, other.data)])
    
    def __mul__(self, scalar):
        """Умножение на скаляр."""
        return Vector([x * scalar for x in self.data])
    
    def dot(self, other):
        """Скалярное произведение."""
        if self.size != other.size:
            raise ValueError(f"Size mismatch: {self.size} vs {other.size}")
        return sum(a * b for a, b in zip(self.data, other.data))
    
    def magnitude(self):
        """Длина вектора (L2 норма)."""
        return sum(x ** 2 for x in self.data) ** 0.5
```

### 8.2 Класс Matrix (полная версия)

```python
class Matrix:
    """
    Матрица с полным набором операций:
    - Сложение/вычитание
    - Скалярное умножение
    - Element-wise умножение
    - Матричное умножение
    - Транспонирование
    - Детерминант
    - Обратная (2×2)
    - Identity
    """
    
    def __init__(self, data):
        self.data = [list(row) for row in data]
        self.rows = len(self.data)
        self.cols = len(self.data[0]) if self.rows > 0 else 0
        self.shape = (self.rows, self.cols)
        
        # Проверка: все строки должны иметь одинаковую длину
        for i, row in enumerate(self.data):
            if len(row) != self.cols:
                raise ValueError(
                    f"Inconsistent row lengths: row 0 has {self.cols}, "
                    f"row {i} has {len(row)}"
                )
    
    def __repr__(self):
        rows_str = "\n  ".join(str(row) for row in self.data)
        return f"Matrix {self.shape}:\n  {rows_str}"
    
    def __add__(self, other):
        """Поэлементное сложение матриц."""
        if self.shape != other.shape:
            raise ValueError(f"Shape mismatch: {self.shape} vs {other.shape}")
        return Matrix([
            [self.data[i][j] + other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])
    
    def __sub__(self, other):
        """Поэлементное вычитание матриц."""
        if self.shape != other.shape:
            raise ValueError(f"Shape mismatch: {self.shape} vs {other.shape}")
        return Matrix([
            [self.data[i][j] - other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])
    
    def scalar_multiply(self, scalar):
        """Умножение матрицы на скаляр."""
        return Matrix([
            [self.data[i][j] * scalar for j in range(self.cols)]
            for i in range(self.rows)
        ])
    
    def element_wise_multiply(self, other):
        """
        Поэлементное умножение (Hadamard product).
        Требование: одинаковые формы.
        """
        if self.shape != other.shape:
            raise ValueError(f"Shape mismatch: {self.shape} vs {other.shape}")
        return Matrix([
            [self.data[i][j] * other.data[i][j] for j in range(self.cols)]
            for i in range(self.rows)
        ])
    
    def matmul(self, other):
        """
        Матричное умножение: self @ other.
        Требование: self.cols == other.rows
        """
        if self.cols != other.rows:
            raise ValueError(
                f"Inner dimensions must match for matmul: "
                f"{self.cols} vs {other.rows}"
            )
        
        result_data = []
        for i in range(self.rows):
            row = []
            for j in range(other.cols):
                # Скалярное произведение i-й строки self на j-й столбец other
                value = sum(
                    self.data[i][k] * other.data[k][j]
                    for k in range(self.cols)
                )
                row.append(value)
            result_data.append(row)
        
        return Matrix(result_data)
    
    def transpose(self):
        """Транспонирование: строки ↔ столбцы."""
        return Matrix([
            [self.data[j][i] for j in range(self.rows)]
            for i in range(self.cols)
        ])
    
    def determinant(self):
        """
        Вычисление детерминанта (только для квадратных матриц).
        Использует рекурсивное разложение по первой строке.
        """
        if self.rows != self.cols:
            raise ValueError(
                f"Determinant only defined for square matrices, "
                f"got {self.shape}"
            )
        
        # Базовые случаи
        if self.shape == (1, 1):
            return self.data[0][0]
        
        if self.shape == (2, 2):
            return (self.data[0][0] * self.data[1][1] - 
                    self.data[0][1] * self.data[1][0])
        
        # Рекурсивное разложение по первой строке
        det = 0
        for j in range(self.cols):
            # Создаём минор (матрица без 0-й строки и j-го столбца)
            minor_data = [
                [self.data[i][k] for k in range(self.cols) if k != j]
                for i in range(1, self.rows)
            ]
            minor = Matrix(minor_data)
            
            # Чередуем знаки: +, -, +, -, ...
            sign = (-1) ** j
            det += sign * self.data[0][j] * minor.determinant()
        
        return det
    
    def inverse_2x2(self):
        """
        Обратная матрица для 2×2.
        Формула: (1/det) × [[d, -b], [-c, a]]
        """
        if self.shape != (2, 2):
            raise ValueError(
                f"inverse_2x2 only works for 2x2 matrices, got {self.shape}"
            )
        
        det = self.determinant()
        if abs(det) < 1e-10:
            raise ValueError(
                f"Matrix is singular (det={det:.2e}), no inverse exists"
            )
        
        a, b = self.data[0][0], self.data[0][1]
        c, d = self.data[1][0], self.data[1][1]
        
        return Matrix([
            [d / det, -b / det],
            [-c / det, a / det]
        ])
    
    @staticmethod
    def identity(n):
        """
        Создаёт единичную матрицу n×n.
        Использование: I = Matrix.identity(3)
        """
        return Matrix([
            [1.0 if i == j else 0.0 for j in range(n)]
            for i in range(n)
        ])
```

### 8.3 Dense Layer

```python
import random

class DenseLayer:
    """
    Полносвязный слой нейросети.
    Forward pass: y = ReLU(W @ x + b)
    """
    
    def __init__(self, input_size, output_size):
        self.input_size = input_size
        self.output_size = output_size
        
        # Xavier initialization
        std = (2 / (input_size + output_size)) ** 0.5
        self.weights = Matrix([
            [random.gauss(0, std) for _ in range(input_size)]
            for _ in range(output_size)
        ])
        
        # Bias = нули
        self.bias = Matrix([[0.0] for _ in range(output_size)])
    
    def forward(self, x):
        """
        Forward pass.
        x: Matrix shape (input_size, 1)
        return: Matrix shape (output_size, 1)
        """
        # Линейная трансформация: z = Wx + b
        z = self.weights.matmul(x) + self.bias
        
        # ReLU activation
        output = Matrix([
            [max(0.0, val) for val in row]
            for row in z.data
        ])
        
        return output


class TwoLayerNet:
    """
    Двухслойная нейросеть:
    Input (3) → Hidden (4) → Output (2)
    """
    
    def __init__(self):
        self.layer1 = DenseLayer(input_size=3, output_size=4)
        self.layer2 = DenseLayer(input_size=4, output_size=2)
    
    def forward(self, x):
        h = self.layer1.forward(x)
        y = self.layer2.forward(h)
        return y
```

```python
import numpy as np

class DenseLayerNumpy:
    """Dense layer на NumPy — в 10 раз меньше кода, в 100 раз быстрее."""
    
    def __init__(self, input_size, output_size):
        # Xavier initialization
        std = np.sqrt(2 / (input_size + output_size))
        self.weights = np.random.randn(output_size, input_size) * std
        self.bias = np.zeros((output_size, 1))
    
    def forward(self, x):
        """
        x: shape (input_size, 1) или (input_size, batch_size)
        return: shape (output_size, 1) или (output_size, batch_size)
        """
        z = self.weights @ x + self.bias  # Broadcasting для bias!
        return np.maximum(0, z)  # ReLU
```

### 9.5 Почему NumPy быстрее?

NumPy использует:

1. **BLAS (Basic Linear Algebra Subprograms):** Оптимизированные библиотеки на C/Fortran
   - OpenBLAS, Intel MKL, Apple Accelerate
   
2. **SIMD (Single Instruction, Multiple Data):** Одна CPU инструкция обрабатывает несколько чисел одновременно

3. **Многопоточность:** Параллельные вычисления на нескольких ядрах

4. **Оптимизация под кэш:** Данные организуются для максимального использования CPU cache
