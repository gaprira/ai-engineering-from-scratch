## 🏛 ИСТОРИЧЕСКИЙ КОНТЕКСТ: ОТ ДРЕВНЕГО ЕГИПТА ДО ТРАНСФОРМЕРОВ

### Эпоха 1: Рождение векторов (1840-е)

Представьте себя в 1843 году. Ирландский математик **Уильям Роуан Гамильтон** гуляет вдоль канала в Дублине. Он одержим идеей: как расширить комплексные числа (которые живут на плоскости) в трехмерное пространство?

Внезапно его осеняет. Он понимает, что нужно **четыре** измерения, а не три. Он вырезает формулу на камне моста Брум-Бридж:

```
i² = j² = k² = ijk = -1
```

Это были **кватернионы** — первые "векторы" в современной математике. Гамильтон не знал, что через 180 лет его изобретение будет использоваться в каждом 3D-движке, каждой игре и каждой нейросети, работающей с 3D-данными.

### Эпоха 2: Матрицы и трансформации (1850-1900)

**Артур Кэли** в 1858 году формализует матричную алгебру. Он показывает, что матрицы — это не просто таблицы чисел. Это **операторы**, которые трансформируют пространство.

Подумайте об этом: когда вы умножаете вектор на матрицу, вы не просто "делаете арифметику". Вы **деформируете само пространство**. Матрица может:
- **Вращать** (rotation)
- **Растягивать** (scaling)
- **Сдвигать** (shearing)
- **Проецировать** (projection)
- **Отражать** (reflection)

Это не абстракция. Это то, что делает каждый слой нейросети.

### Эпоха 3: Векторные пространства и абстракция (1920-1960)

**Давид Гильберт** и **Стефан Банах** абстрагируют понятие вектора. Вектор — это уже не "стрелка в пространстве". Это **любой объект**, который можно складывать и умножать на число.

Функция может быть вектором. Полином может быть вектором. Даже нейросеть может быть вектором (в пространстве параметров).

Эта абстракция позволила математикам работать с **бесконечномерными пространствами**. И именно это нужно для понимания kernel methods, Gaussian processes и функционального анализа в ML.

### Эпоха 4: Компьютерная революция (1960-2000)

Появляются первые компьютеры. **Джеймс Уилкинсон** и **Джин Голуб** разрабатывают численные методы для решения систем линейных уравнений. Алгоритмы вроде **QR-разложения** и **SVD** (Singular Value Decomposition) становятся основой научных вычислений.

В 1965 году **Джон Тьюки** изобретает **БПФ** (Быстрое Преобразование Фурье) — алгоритм, который сводит сложность с O(n²) к O(n log n). Без БПФ не было бы ни MP3, ни JPEG, ни современной обработки сигналов.

### Эпоха 5: Эра глубокого обучения (2012-настоящее)

2012 год. **AlexNet** побеждает в ImageNet. Что внутри? Сверточные слои, которые есть не что иное, как **специализированные матричные умножения**.

2017 год. Появляется **"Attention Is All You Need"**. Трансформеры используют **матрицы внимания** (attention matrices), чтобы решать, какие части входных данных важны. Механизм self-attention — это буквально:

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

Где Q, K, V — матрицы. Всё внимание — это матричное умножение + softmax.

2021 год. **LoRA** (Low-Rank Adaptation) позволяет файнтюнить LLM, обновляя не все 175 миллиардов параметров GPT-3, а только низкоранговые матрицы. Это линейная алгебра в чистом виде: если матрица весов W имеет ранг r, мы можем аппроксимировать её как:

```
W ≈ W₀ + ΔW = W₀ + AB
```

Где A ∈ ℝ^(d×r) и B ∈ ℝ^(r×k), и r << min(d, k). Вместо обновления 4096×4096 = 16.7M параметров, мы обновляем 4096×16 + 16×4096 = 131K параметров. **Экономия в 127 раз!**

## 📐 ЧАСТЬ 1: ВЕКТОРЫ — ТОЧКИ В ПРОСТРАНСТВЕ

### 1.1 Что такое вектор? (Интуитивное определение)

**Определение:** Вектор — это упорядоченный список чисел.

```
v = [3, 2]     # 2D вектор
u = [1, 4, -2] # 3D вектор
w = [0.1, -0.3, 0.7, ..., 0.2] # 768D вектор (эмбеддинг слова)
```

Но это сухое определение. Давайте копнем глубже.

**Геометрическая интерпретация:** Вектор — это **стрелка** из начала координат в точку с заданными координатами.

```
y
↑
|   v = [3, 2]
|   •
|  /
| /
|/_______→ x
```

Вектор `[3, 2]` говорит: "Иди на 3 единицы вправо и на 2 единицы вверх от начала координат".

### 1.2 Векторы в AI: Эмбеддинги

В машинном обучении векторы представляют **смысл**. Это одна из самых красивых идей в AI.

**Пример:** Возьмем слово "король". Как нейросеть "понимает" его смысл?

Она превращает слово в вектор из 768 чисел (в BERT) или 12288 чисел (в GPT-4):

```python
king_embedding = [0.23, -0.15, 0.87, ..., 0.42]  # 768 чисел
```

Что означает каждое число? Мы не знаем! Это **латентные признаки** (latent features), которые нейросеть выучила сама. Но мы знаем, что:

```python
king - man + woman ≈ queen
```

Это знаменитое свойство word2vec (Mikolov et al., 2013). Векторные операции соответствуют **семантическим операциям**.

**Почему это работает?** Потому что нейросеть выучила, что "король" и "королева" отличаются примерно так же, как "мужчина" и "женщина". И эта разница закодирована в векторном пространстве.

### 1.3 Размерность вектора

**Размерность** (dimension) — это количество чисел в векторе.

```python
v = [1, 2, 3]      # dim = 3 (3D пространство)
u = [0.1] * 768    # dim = 768 (BERT embedding)
w = [0.5] * 12288  # dim = 12288 (GPT-4 embedding)
```

**Интуиция:** Размерность — это количество "степеней свободы". В 3D пространстве вы можете двигаться в 3 направлениях: вперед/назад, влево/вправо, вверх/вниз.

В 768-мерном пространстве BERT у вас есть 768 "направлений", в которых может изменяться смысл слова. Это может быть "позитивность", "формальность", "абстрактность" и еще 765 признаков, которые мы не можем назвать.

### 1.4 Операции над векторами

#### Сложение векторов

**Геометрически:** Сложение векторов — это "следуй по первой стрелке, затем по второй".

```
    a + b
      ↑
     /
    / 
   /   b
  /   ↑
 /   /
•———→ a
```

**Алгебраически:** Складываем соответствующие компоненты.

```python
a = [1, 2]
b = [3, 1]
a + b = [1+3, 2+1] = [4, 3]
```

**Код с нуля:**

```python
class Vector:
    def __init__(self, components):
        self.components = list(components)
        self.dim = len(self.components)
    
    def __add__(self, other):
        """Сложение векторов: a + b"""
        if self.dim != other.dim:
            raise ValueError("Vectors must have same dimension")
        return Vector([a + b for a, b in zip(self.components, other.components)])
```

#### Умножение на скаляр

**Геометрически:** Растягиваем или сжимаем вектор.

```python
v = [2, 1]
2 * v = [4, 2]    # Растянули в 2 раза
0.5 * v = [1, 0.5] # Сжали в 2 раза
-1 * v = [-2, -1]  # Развернули на 180°
```

**Код:**

```python
def __mul__(self, scalar):
    """Умножение на число: c * v"""
    return Vector([c * x for c in self.components])
```

#### Длина вектора (норма)

**Геометрически:** Длина стрелки.

**Формула:** По теореме Пифагора:

```
|v| = √(v₁² + v₂² + ... + vₙ²)
```

**Пример:**

```python
v = [3, 4]
|v| = √(3² + 4²) = √(9 + 16) = √25 = 5
```

**Код:**

```python
def magnitude(self):
    """Длина вектора (L2 норма)"""
    return sum(x**2 for x in self.components) ** 0.5
```

**Зачем это нужно в AI?**
- **Нормализация:** Мы часто хотим превратить вектор в "единичный" (длины 1), сохранив направление.
- **Расстояние:** Расстояние между двумя точками = длина вектора разности: `|a - b|`.
- **Регуляризация:** L2-регуляризация штрафует большие веса: `loss += λ * |w|²`.

## 📏 ЧАСТЬ 2: СКАЛЯРНОЕ ПРОИЗВЕДЕНИЕ — МЕРА ПОХОЖЕСТИ

### 2.1 Определение

**Скалярное произведение** (dot product, inner product) двух векторов — это сумма произведений их соответствующих компонентов:

```
a · b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ
```

**Пример:**

```python
a = [1, 2, 3]
b = [4, 5, 6]
a · b = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

**Код:**

```python
def dot(self, other):
    """Скалярное произведение: a · b"""
    if self.dim != other.dim:
        raise ValueError("Vectors must have same dimension")
    return sum(a * b for a, b in zip(self.components, other.components))
```

### 2.2 Геометрический смысл

Вот здесь начинается магия. Скалярное произведение имеет глубокую геометрическую интерпретацию:

```
a · b = |a| × |b| × cos(θ)
```

Где θ — угол между векторами.

**Что это значит?**

1. **Если векторы сонаправлены** (θ = 0°, cos(0°) = 1):
   ```
   a · b = |a| × |b| × 1 = максимальное значение
   ```
   Векторы "смотрят в одну сторону". Они **похожи**.

2. **Если векторы перпендикулярны** (θ = 90°, cos(90°) = 0):
   ```
   a · b = |a| × |b| × 0 = 0
   ```
   Векторы **ортогональны**. Они не связаны.

3. **Если векторы противоположны** (θ = 180°, cos(180°) = -1):
   ```
   a · b = |a| × |b| × (-1) = минимальное значение
   ```
   Векторы "смотрят в разные стороны". Они **противоположны**.

**Визуализация:**

```
  Сонаправлены:        Перпендикулярны:      Противоположны:
      b                    b                     b
      ↑                    ↑                     ↓
     /                     |                     |
    /                      |                     |
   / θ=0°                  | θ=90°               | θ=180°
  /                        |                     |
 •————→ a                •————→ a              •————→ a
 
 a·b > 0 (большое)      a·b = 0               a·b < 0
```

### 2.3 Косинусное сходство

Проблема скалярного произведения: оно зависит от длин векторов. Длинные векторы дают большое значение, даже если они не очень похожи.

**Решение:** Нормализовать на длины векторов:

```
cosine_similarity(a, b) = (a · b) / (|a| × |b|)
```

Это просто `cos(θ)` — косинус угла между векторами.

**Свойства:**
- Диапазон: от -1 до 1
- `1` = полностью сонаправлены
- `0` = перпендикулярны (не связаны)
- `-1` = полностью противоположны

**Код:**

```python
def cosine_similarity(self, other):
    """Косинусное сходство: нормализованная мера похожести"""
    return self.dot(other) / (self.magnitude() * other.magnitude())
```

### 2.4 Применение в AI: Векторный поиск

**Сценарий:** У вас есть база знаний из 10 000 документов. Пользователь задает вопрос. Как найти самые релевантные документы?

**Решение:** RAG (Retrieval-Augmented Generation)

```python
# 1. Превращаем все документы в векторы (эмбеддинги)
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

documents = [
    "Python — это язык программирования",
    "Москва — столица России",
    "Нейросети используются в AI",
    # ... 10 000 документов
]

doc_embeddings = model.encode(documents)  # Shape: (10000, 384)

# 2. Превращаем запрос пользователя в вектор
query = "Как работают нейросети?"
query_embedding = model.encode(query)  # Shape: (384,)

# 3. Вычисляем косинусное сходство с каждым документом
import numpy as np

similarities = []
for doc_emb in doc_embeddings:
    sim = np.dot(query_embedding, doc_emb) / (
        np.linalg.norm(query_embedding) * np.linalg.norm(doc_emb)
    )
    similarities.append(sim)

# 4. Находим топ-5 самых похожих документов
top_indices = np.argsort(similarities)[-5:][::-1]
top_docs = [documents[i] for i in top_indices]

print("Самые релевантные документы:")
for doc in top_docs:
    print(f"  - {doc}")
```

**Результат:** Документ "Нейросети используются в AI" будет иметь **наивысшее косинусное сходство** с запросом "Как работают нейросети?", потому что их векторы pointing in roughly the same direction в эмбеддинг-пространстве.

**Это и есть поиск по смыслу, а не по ключевым словам!**

## 🔄 ЧАСТЬ 3: МАТРИЦЫ — ТРАНСФОРМАЦИИ ПРОСТРАНСТВА

### 3.1 Что такое матрица?

**Определение:** Матрица — это прямоугольная таблица чисел.

```
A = [1  2  3]
    [4  5  6]
```

Это матрица 2×3 (2 строки, 3 столбца).

Но это сухое определение. **Геометрически матрица — это трансформация пространства.**

### 3.2 Матрица как функция

Подумайте о матрице как о **функции**, которая принимает вектор и возвращает другой вектор:

```
f(v) = A × v
```

**Пример:** Матрица поворота на 90° против часовой стрелки:

```
R = [ 0  -1]
    [ 1   0]
```

Применим к вектору `[1, 0]` (точка на оси X):

```
R × [1, 0] = [0×1 + (-1)×0, 1×1 + 0×0] = [0, 1]
```

Точка `[1, 0]` превратилась в `[0, 1]`. Она **повернулась на 90°**!

**Визуализация:**

```
До:              После:
  y                y
  ↑                ↑
  |                | [0,1]
  |                |  •
  |   [1,0]        | /
  |     •          |/
  |    /           •————→ x
  |   /
  •————→ x
```

### 3.3 Типы матричных трансформаций

#### 1. Поворот (Rotation)

```
R(θ) = [cos(θ)  -sin(θ)]
       [sin(θ)   cos(θ)]
```

Для θ = 90°:

```
R(90°) = [0  -1]
         [1   0]
```

#### 2. Масштабирование (Scaling)

```
S = [2  0]
    [0  3]
```

Растягивает X в 2 раза, Y в 3 раза.

#### 3. Отражение (Reflection)

```
F = [-1   0]
    [ 0   1]
```

Отражает относительно оси Y.

#### 4. Сдвиг (Shearing)

```
H = [1  1]
    [0  1]
```

"Наклоняет" пространство.

### 3.4 Матричное умножение

**Правило:** Чтобы умножить матрицу A на матрицу B, нужно:
- Количество столбцов A = количеству строк B
- Результат: матрица с размером (строки A) × (столбцы B)

**Формула:**

```
(A × B)[i, j] = Σ(A[i, k] × B[k, j])  для всех k
```

**Пример:**

```
A = [1  2]    B = [5  6]
    [3  4]        [7  8]

A × B = [1×5 + 2×7,  1×6 + 2×8]   = [19  22]
        [3×5 + 4×7,  3×6 + 4×8]     [43  50]
```

**Код с нуля:**

```python
class Matrix:
    def __init__(self, rows):
        self.rows = [list(row) for row in rows]
        self.shape = (len(self.rows), len(self.rows[0]))
    
    def __matmul__(self, other):
        """Матричное умножение: A @ B"""
        if isinstance(other, Vector):
            # Матрица × Вектор
            return Vector([
                sum(self.rows[i][j] * other.components[j] 
                    for j in range(self.shape[1]))
                for i in range(self.shape[0])
            ])
        
        # Матрица × Матрица
        if self.shape[1] != other.shape[0]:
            raise ValueError("Incompatible shapes for matrix multiplication")
        
        result_rows = []
        for i in range(self.shape[0]):
            row = []
            for j in range(other.shape[1]):
                value = sum(
                    self.rows[i][k] * other.rows[k][j]
                    for k in range(self.shape[1])
                )
                row.append(value)
            result_rows.append(row)
        
        return Matrix(result_rows)
```

### 3.5 Матрицы в AI: Слои нейросети

**Полносвязный слой** (fully connected layer) — это просто матричное умножение + нелинейность:

```python
def linear_layer(x, W, b):
    """
    x: входной вектор (dim: input_size)
    W: матрица весов (shape: output_size × input_size)
    b: вектор смещения (dim: output_size)
    """
    z = W @ x + b  # Линейная трансформация
    return relu(z) # Нелинейность

# Пример
x = [1.0, 0.5, -0.3]  # Вход (3 признака)
W = [[0.1, -0.2, 0.3],   # Веса для нейрона 1
     [0.4,  0.5, -0.1]]  # Веса для нейрона 2
b = [0.0, 0.0]           # Смещения

output = linear_layer(x, W, b)
# output = [0.1×1.0 + (-0.2)×0.5 + 0.3×(-0.3) + 0.0,
#           0.4×1.0 + 0.5×0.5 + (-0.1)×(-0.3) + 0.0]
#        = [-0.09, 0.68]
```

**Что произошло?**
1. Входной вектор `[1.0, 0.5, -0.3]` (3D) был **трансформирован** матрицей W.
2. Результат: вектор `[-0.09, 0.68]` (2D).
3. Мы **спроецировали** 3D пространство в 2D пространство.

**Обучение нейросети = подбор правильной матрицы W**, которая трансформирует входные данные в правильные выходы.

### 3.6 Транспонирование

**Транспонирование** — это "переворот" матрицы: строки становятся столбцами.

```
A = [1  2  3]    Aᵀ = [1  4]
    [4  5  6]         [2  5]
                      [3  6]
```

**Код:**

```python
def transpose(self):
    """Транспонирование матрицы"""
    return Matrix([
        [self.rows[j][i] for j in range(self.shape[0])]
        for i in range(self.shape[1])
    ])
```

**Зачем это нужно?**

В механизме **attention** трансформеров:

```
Attention(Q, K, V) = softmax(Q × Kᵀ / √d_k) × V
```

Мы транспонируем K, чтобы можно было вычислить **попарное сходство** между всеми запросами и ключами.

## 🔗 ЧАСТЬ 4: ЛИНЕЙНАЯ НЕЗАВИСИМОСТЬ И РАНГ

### 4.1 Линейная комбинация

**Определение:** Линейная комбинация векторов — это сумма векторов, умноженных на скаляры:

```
c₁v₁ + c₂v₂ + ... + cₙvₙ
```

**Пример:**

```python
v1 = [1, 0]
v2 = [0, 1]

# Линейная комбинация
3*v1 + 2*v2 = [3, 0] + [0, 2] = [3, 2]
```

### 4.2 Линейная независимость

**Определение:** Набор векторов **линейно независим**, если ни один из них нельзя выразить как линейную комбинацию остальных.

**Пример 1: Независимые векторы**

```python
v1 = [1, 0, 0]  # Ось X
v2 = [0, 1, 0]  # Ось Y
v3 = [0, 0, 1]  # Ось Z
```

Никакой из этих векторов нельзя получить из двух других. Они **независимы**.

**Пример 2: Зависимые векторы**

```python
v1 = [1, 0, 0]
v2 = [0, 1, 0]
v3 = [2, 1, 0]  # v3 = 2*v1 + v2
```

`v3` можно выразить через `v1` и `v2`. Эти векторы **зависимы**.

**Геометрически:** Все три вектора лежат в плоскости XY. Они не могут "достать" до оси Z.

### 4.3 Span (линейная оболочка)

**Определение:** Span набора векторов — это множество всех возможных линейных комбинаций этих векторов.

**Пример:**

```python
v1 = [1, 0, 0]
v2 = [0, 1, 0]

span({v1, v2}) = {c₁*v1 + c₂*v2 | c₁, c₂ ∈ ℝ}
               = {[c₁, c₂, 0] | c₁, c₂ ∈ ℝ}
               = Вся плоскость XY
```

Если добавить `v3 = [0, 0, 1]`:

```python
span({v1, v2, v3}) = Всё 3D пространство
```

### 4.4 Ранг матрицы

**Определение:** Ранг матрицы — это количество **линейно независимых** столбцов (или строк).

**Пример 1: Полный ранг**

```
A = [1  0  0]
    [0  1  0]
    [0  0  1]

rank(A) = 3 (все столбцы независимы)
```

**Пример 2: Неполный ранг**

```
B = [1  2  3]
    [2  4  6]

rank(B) = 1 (вторая строка = 2 × первая строка)
```

**Зачем это нужно в AI?**

1. **Мультиколлинеарность:** Если признаки линейно зависимы, матрица XᵀX становится **вырожденной** (rank < n). Невозможно найти единственное решение для весов линейной регрессии.

2. **LoRA:** Мы **намеренно** ограничиваем ранг матрицы обновлений:
   ```
   ΔW = A × B,  где rank(A) = rank(B) = r << n
   ```
   Это позволяет файнтюнить LLM, обновляя только ~1% параметров.

3. **PCA (Principal Component Analysis):** Мы находим **главные компоненты** — направления с максимальной дисперсией. Количество компонент = ранг матрицы ковариации.

### 4.5 Проверка линейной независимости (алгоритм)

**Метод:** Гауссово исключение (приведение к ступенчатому виду).

**Алгоритм:**
1. Составляем матрицу из векторов (каждый вектор — строка)
2. Приводим к ступенчатому виду (row echelon form)
3. Считаем количество ненулевых строк = ранг
4. Если ранг = количеству векторов → независимы

**Код:**

```python
def is_linearly_independent(vectors):
    """Проверка линейной независимости набора векторов"""
    n = len(vectors)
    dim = len(vectors[0].components)
    
    # Создаем матрицу из векторов
    mat = [v.components[:] for v in vectors]
    
    # Гауссово исключение
    rank = 0
    for col in range(dim):
        # Ищем опорный элемент (pivot)
        pivot = None
        for row in range(rank, len(mat)):
            if abs(mat[row][col]) > 1e-10:
                pivot = row
                break
        
        if pivot is None:
            continue  # Столбец не содержит ненулевых элементов
        
        # Меняем строки местами
        mat[rank], mat[pivot] = mat[pivot], mat[rank]
        
        # Нормализуем опорную строку
        scale = mat[rank][col]
        mat[rank] = [x / scale for x in mat[rank]]
        
        # Обнуляем элементы ниже и выше опорного
        for row in range(len(mat)):
            if row != rank and abs(mat[row][col]) > 1e-10:
                factor = mat[row][col]
                mat[row] = [mat[row][j] - factor * mat[rank][j] 
                           for j in range(dim)]
        
        rank += 1
    
    # Если ранг = количеству векторов → независимы
    return rank == n

# Пример использования
v1 = Vector([1, 0, 0])
v2 = Vector([0, 1, 0])
v3 = Vector([0, 0, 1])

print(is_linearly_independent([v1, v2, v3]))  # True

v4 = Vector([1, 1, 0])
print(is_linearly_independent([v1, v2, v4]))  # False (v4 = v1 + v2)
```

## 🎯 ЧАСТЬ 5: ПРОЕКЦИИ И ОРТОГОНАЛИЗАЦИЯ

### 5.1 Проекция вектора на вектор

**Задача:** Дан вектор **a**. Найти его **компоненту** в направлении вектора **b**.

**Геометрически:** Это "тень" вектора a на векторе b.

```
        a
        ↑
       /|
      / |
     /  | ← residual (перпендикулярно b)
    /   |
   /    |
  •—————→ b
  ↑
  projection of a onto b
```

**Формула:**

```
proj_b(a) = (a · b / b · b) × b
```

**Интуиция:**
- `a · b` — насколько a "смотрит" в сторону b
- `b · b` — длина b в квадрате (нормализация)
- Умножаем на b — получаем вектор в направлении b

**Пример:**

```python
a = [3, 4]
b = [1, 0]  # Ось X

proj_b(a) = (3×1 + 4×0) / (1×1 + 0×0) × [1, 0]
          = 3 / 1 × [1, 0]
          = [3, 0]
```

**Код:**

```python
def project(a, b):
    """Проекция вектора a на вектор b"""
    scalar = a.dot(b) / b.dot(b)
    return Vector([scalar * x for x in b.components])

# Пример
a = Vector([3, 4])
b = Vector([1, 0])
proj = project(a, b)
print(proj)  # Vector([3, 0])
```

**Применение в AI:**

1. **Линейная регрессия:** Решение задачи линейной регрессии — это **проекция** вектора наблюдений y на пространство столбцов матрицы X.

2. **Attention в трансформерах:** Query проецируется на Key, чтобы определить "насколько этот ключ релевантен запросу".

3. **PCA:** Данные проецируются на главные компоненты (направления максимальной дисперсии).

### 5.2 Ортогональность

**Определение:** Два вектора **ортогональны** (перпендикулярны), если их скалярное произведение равно нулю:

```
a · b = 0  ⟺  a ⊥ b
```

**Пример:**

```python
a = [1, 0]
b = [0, 1]
a · b = 1×0 + 0×1 = 0  # Ортогональны!
```

### 5.3 Ортонормированный базис

**Определение:** Набор векторов **ортонормирован**, если:
1. Все векторы попарно ортогональны
2. Все векторы имеют длину 1

**Пример:** Стандартный базис в 3D:

```python
e1 = [1, 0, 0]
e2 = [0, 1, 0]
e3 = [0, 0, 1]

# Проверка
e1 · e2 = 0  ✓
e1 · e3 = 0  ✓
e2 · e3 = 0  ✓
|e1| = 1     ✓
|e2| = 1     ✓
|e3| = 1     ✓
```

**Зачем это нужно?**

Ортонормированный базис — это "идеальная система координат":
- Нет корреляции между осями
- Масштаб одинаков по всем осям
- Вычисления устойчивы численно

### 5.4 Процесс Грама-Шмидта

**Задача:** Дан набор линейно независимых векторов. Превратить его в **ортонормированный базис**.

**Алгоритм:**

```
Вход: v1, v2, v3, ... (линейно независимые)

Шаг 1: u1 = v1 / |v1|  (нормализуем первый вектор)

Шаг 2: w2 = v2 - proj_u1(v2)  (убираем компоненту в направлении u1)
       u2 = w2 / |w2|         (нормализуем)

Шаг 3: w3 = v3 - proj_u1(v3) - proj_u2(v3)  (убираем компоненты в направлениях u1 и u2)
       u3 = w3 / |w3|                         (нормализуем)

...

Выход: u1, u2, u3, ... (ортонормированный базис)
```

**Интуиция:**
1. Берем первый вектор, нормализуем.
2. Берем второй вектор, **вычитаем его проекцию** на первый (убираем "похожесть"), нормализуем.
3. Берем третий вектор, вычитаем проекции на **все предыдущие**, нормализуем.
4. Повторяем.

**Код:**

```python
def gram_schmidt(vectors):
    """
    Процесс Грама-Шмидта: превращает набор линейно независимых векторов
    в ортонормированный базис.
    """
    orthonormal = []
    
    for v in vectors:
        # Начинаем с исходного вектора
        w = v
        
        # Вычитаем проекции на все уже найденные ортонормированные векторы
        for u in orthonormal:
            proj = project(w, u)
            w = w - proj
        
        # Проверяем, что вектор не нулевой (линейно независим от предыдущих)
        if w.magnitude() < 1e-10:
            continue  # Пропускаем линейно зависимые векторы
        
        # Нормализуем
        orthonormal.append(w.normalize())
    
    return orthonormal

# Пример использования
v1 = Vector([1, 0, 0])
v2 = Vector([1, 1, 0])
v3 = Vector([1, 1, 1])

basis = gram_schmidt([v1, v2, v3])

print("Ортонормированный базис:")
for i, u in enumerate(basis):
    print(f"  u{i+1} = {u}")
    print(f"    |u{i+1}| = {u.magnitude():.6f}")

# Проверка ортогональности
print("\nПроверка ортогональности:")
print(f"  u1 · u2 = {basis[0].dot(basis[1]):.6f}")
print(f"  u1 · u3 = {basis[0].dot(basis[2]):.6f}")
print(f"  u2 · u3 = {basis[1].dot(basis[2]):.6f}")
```

**Результат:**

```
Ортонормированный базис:
  u1 = Vector([1.0, 0.0, 0.0])
    |u1| = 1.000000
  u2 = Vector([0.0, 1.0, 0.0])
    |u2| = 1.000000
  u3 = Vector([0.0, 0.0, 1.0])
    |u3| = 1.000000

Проверка ортогональности:
  u1 · u2 = 0.000000
  u1 · u3 = 0.000000
  u2 · u3 = 0.000000
```

**Применение в AI:**

1. **QR-разложение:** Gram-Schmidt — это основа QR-разложения:
   ```
   A = Q × R
   ```
   Где Q — ортогональная матрица, R — верхнетреугольная. Используется для решения систем линейных уравнений и нахождения собственных значений.

2. **Orthogonal initialization:** Инициализация весов нейросети ортогональными матрицами улучшает обучение (Saxe et al., 2013).

3. **Whitening:** Преобразование данных так, чтобы признаки стали некоррелированными и имели единичную дисперсию.

class Vector:
    """
    Вектор — это упорядоченный список чисел, представляющий точку
    или направление в n-мерном пространстве.
    """
    
    def __init__(self, components):
        self.components = list(components)
        self.dim = len(self.components)
    
    def __add__(self, other):
        """Сложение векторов: a + b"""
        if self.dim != other.dim:
            raise ValueError(f"Cannot add vectors of different dimensions: {self.dim} vs {other.dim}")
        return Vector([a + b for a, b in zip(self.components, other.components)])
    
    def __sub__(self, other):
        """Вычитание векторов: a - b"""
        if self.dim != other.dim:
            raise ValueError(f"Cannot subtract vectors of different dimensions: {self.dim} vs {other.dim}")
        return Vector([a - b for a, b in zip(self.components, other.components)])
    
    def __mul__(self, scalar):
        """Умножение на скаляр: c * v"""
        return Vector([scalar * x for x in self.components])
    
    def __rmul__(self, scalar):
        """Умножение на скаляр (справа): v * c"""
        return self.__mul__(scalar)
    
    def dot(self, other):
        """
        Скалярное произведение: a · b
        
        Геометрический смысл: мера похожести двух векторов.
        a · b = |a| × |b| × cos(θ)
        
        Где θ — угол между векторами.
        """
        if self.dim != other.dim:
            raise ValueError(f"Cannot compute dot product of vectors with different dimensions: {self.dim} vs {other.dim}")
        return sum(a * b for a, b in zip(self.components, other.components))
    
    def magnitude(self):
        """
        Длина вектора (L2 норма).
        
        Формула: |v| = √(v₁² + v₂² + ... + vₙ²)
        """
        return sum(x**2 for x in self.components) ** 0.5
    
    def normalize(self):
        """
        Нормализация: превращает вектор в единичный (длины 1),
        сохраняя направление.
        
        Формула: v_normalized = v / |v|
        """
        mag = self.magnitude()
        if mag < 1e-10:
            raise ValueError("Cannot normalize zero vector")
        return Vector([x / mag for x in self.components])
    
    def cosine_similarity(self, other):
        """
        Косинусное сходство: нормализованная мера похожести.
        
        Диапазон: от -1 до 1
        - 1: векторы сонаправлены
        - 0: векторы перпендикулярны
        - -1: векторы противоположны
        
        Это основа векторного поиска в RAG!
        """
        mag_product = self.magnitude() * other.magnitude()
        if mag_product < 1e-10:
            raise ValueError("Cannot compute cosine similarity with zero vector")
        return self.dot(other) / mag_product
    
    def __repr__(self):
        return f"Vector({self.components})"


class Matrix:
    """
    Матрица — это прямоугольная таблица чисел, представляющая
    линейную трансформацию пространства.
    """
    
    def __init__(self, rows):
        self.rows = [list(row) for row in rows]
        self.shape = (len(self.rows), len(self.rows[0]))
    
    def __matmul__(self, other):
        """
        Матричное умножение: A @ B
        
        Правило: (строки A) × (столбцы B)
        Результат[i, j] = Σ(A[i, k] × B[k, j])
        """
        if isinstance(other, Vector):
            # Матрица × Вектор
            if self.shape[1] != other.dim:
                raise ValueError(f"Incompatible shapes: matrix {self.shape} and vector dim {other.dim}")
            
            return Vector([
                sum(self.rows[i][j] * other.components[j] 
                    for j in range(self.shape[1]))
                for i in range(self.shape[0])
            ])
        
        elif isinstance(other, Matrix):
            # Матрица × Матрица
            if self.shape[1] != other.shape[0]:
                raise ValueError(f"Incompatible shapes for matrix multiplication: {self.shape} and {other.shape}")
            
            result_rows = []
            for i in range(self.shape[0]):
                row = []
                for j in range(other.shape[1]):
                    value = sum(
                        self.rows[i][k] * other.rows[k][j]
                        for k in range(self.shape[1])
                    )
                    row.append(value)
                result_rows.append(row)
            
            return Matrix(result_rows)
        
        else:
            raise TypeError(f"Cannot multiply Matrix with {type(other)}")
    
    def transpose(self):
        """
        Транспонирование: строки становятся столбцами.
        
        A[i, j] → Aᵀ[j, i]
        """
        return Matrix([
            [self.rows[j][i] for j in range(self.shape[0])]
            for i in range(self.shape[1])
        ])
    
    def __repr__(self):
        rows_str = "\n  ".join(str(row) for row in self.rows)
        return f"Matrix(\n  {rows_str}\n)"

def project(a, b):
    """
    Проекция вектора a на вектор b.
    
    Геометрически: "тень" вектора a на направлении b.
    
    Формула: proj_b(a) = (a · b / b · b) × b
    """
    scalar = a.dot(b) / b.dot(b)
    return Vector([scalar * x for x in b.components])

def gram_schmidt(vectors):
    """
    Процесс Грама-Шмидта: превращает набор линейно независимых векторов
    в ортонормированный базис.
    
    Алгоритм:
    1. Берем первый вектор, нормализуем.
    2. Берем второй вектор, вычитаем проекцию на первый, нормализуем.
    3. Берем третий вектор, вычитаем проекции на все предыдущие, нормализуем.
    4. Повторяем.
    
    Результат: все векторы попарно ортогональны и имеют длину 1.
    """
    orthonormal = []
    
    for v in vectors:
        w = v
        
        # Вычитаем проекции на все уже найденные ортонормированные векторы
        for u in orthonormal:
            proj = project(w, u)
            w = w - proj
        
        # Проверяем, что вектор не нулевой
        if w.magnitude() < 1e-10:
            continue
        
        # Нормализуем
        orthonormal.append(w.normalize())
    
    return orthonormal

## 📊 ЧАСТЬ 7: СРАВНЕНИЕ С NUMPY (ЧТО ВЫ БУДЕТЕ ИСПОЛЬЗОВАТЬ НА ПРАКТИКЕ)

Теперь, когда вы понимаете, как всё работает "под капотом", давайте посмотрим, как это делается в **NumPy** — библиотеке, которую вы будете использовать каждый день.

### 7.1 Векторы в NumPy

```python
import numpy as np

# Создание векторов
a = np.array([1, 2, 3], dtype=float)
b = np.array([4, 5, 6], dtype=float)

# Операции
print(f"a + b = {a + b}")                    # Сложение
print(f"a · b = {np.dot(a, b)}")             # Скалярное произведение
print(f"|a| = {np.linalg.norm(a):.4f}")      # Длина
print(f"cosine = {np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)):.4f}")
```

### 7.2 Матрицы в NumPy

```python
# Создание матриц
W = np.random.randn(2, 3) * 0.1  # 2×3 матрица
x = np.array([1.0, 0.5, -0.3])

# Матричное умножение
y = W @ x  # или np.matmul(W, x)
print(f"Wx = {y}")

# Транспонирование
W_T = W.T  # или np.transpose(W)

```

### 7.3 Ранг, проекция и QR в NumPy

```python
# Ранг матрицы
A = np.array([[1, 2], [2, 4]])
print(f"Rank: {np.linalg.matrix_rank(A)}")

# Проекция
a = np.array([3, 4])
b = np.array([1, 0])
proj = (np.dot(a, b) / np.dot(b, b)) * b
print(f"Projection: {proj}")

# QR-разложение
Q, R = np.linalg.qr(np.random.randn(3, 3))
print(f"Q is orthogonal: {np.allclose(Q @ Q.T, np.eye(3))}")
print(f"R is upper triangular: {np.allclose(R, np.triu(R))}")
```

### 7.4 Почему NumPy быстрее?

NumPy использует **оптимизированные BLAS/LAPACK библиотеки** (OpenBLAS, MKL), написанные на C и Fortran. Они используют:
- **SIMD-инструкции** (одна инструкция — много данных)
- **Многопоточность**
- **Оптимизацию под кэш процессора**

Ваш Python-код работает в **100-1000 раз медленнее** NumPy для больших матриц.
